# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Use [GitHub Security Advisories](https://github.com/FFidan/Jarvis-RD-Assistant/security/advisories/new) to report privately. You will receive an acknowledgement within 5 business days.

## Supported versions

The `master` branch is the only actively-supported release line. Fixes are not back-ported to prior tags.

## Threat model + operational guidance

The full threat model, identity boundaries, hardening checklist, and known residual risks live in [`docs/SECURITY.md`](docs/SECURITY.md) and [`docs/known-residual-risks.md`](docs/known-residual-risks.md). Read those before deploying outside a single-user homelab.
