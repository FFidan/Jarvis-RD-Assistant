# Documentation build dependencies — dev/docs-only, NO runtime impact.
#
# These packages are NEVER imported by any service, lib, or test.
# They are used exclusively by `mkdocs build` (local dev) and the
# `.github/workflows/docs.yml` GitHub Actions job that deploys to gh-pages.
#
# Why these two packages:
#   mkdocs-material  — Material theme; provides the look/feel, nav, search.
#   mkdocs-include-markdown-plugin — lets us include root-level Markdown files
#     (README.md, db/migrations/README.md) inside the docs/ tree WITHOUT
#     moving or duplicating canonical files. Thin shims in docs/ use
#     `--8<-- "path"` to inline remote content at build time.
#     This is the ONLY plugin needed for the hybrid no-file-move approach.
#
# Pin minor versions so CI is reproducible; bump deliberately.
mkdocs-material==9.7.7
mkdocs-include-markdown-plugin==7.3.0
